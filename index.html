Database Basics

Understand how databases store and organize data.

What is a Database?

A database is a structured place where we store, manage and retrieve data.

  • Stores application data
  • Organizes information
  • Allows searching and filtering
  • Supports CRUD operations

SQL Structure

SQL databases organize data using tables.

  • Database
  • Table
  • Rows
  • Columns
  • Primary Key

MongoDB Structure

MongoDB is a NoSQL database that stores data in document-based collections.

  • Database
  • Collection
  • Document
  • Fields

Primary Key

A primary key uniquely identifies each record in a SQL table.

  • Must be unique
  • Cannot be NULL
  • Identifies each row

Example

In a students table, the id column can be used as the primary key because every student has a unique ID.

SQL vs MongoDB

Understand the basic difference between SQL and MongoDB.

SQL MongoDB
Relational database NoSQL database
Uses tables Uses collections
Uses rows Uses documents
Uses columns Uses fields
Usually uses a defined schema Flexible document structure
Uses SQL queries Uses MongoDB queries

Backend Installation Guide

Set up Node.js, Express.js and Supabase for full-stack projects.

1

Install Node.js

Download a compatible Node.js LTS version and install it on your computer.


Download Node.js
2

Verify Installation

Open the VS Code terminal or Command Prompt and run these commands. 

node -v
npm -v
3

Create Backend

Open your project folder in VS Code, enter the backend directory and initialize npm. 

mkdir backend
cd backend
npm init -y

Important npm Commands

Run these commands inside the backend folder after installing Node.js. 

npm init -y
npm install express cors dotenv @supabase/supabase-js ws
npm install --save-dev nodemon
npm init -y npm install express cors dotenv @supabase/supabase-js ws npm install --save-dev nodemon

Important npm Packages and Their Uses

Package Use
express Create backend APIs and handle HTTP requests.
cors Configure cross-origin requests between frontend and backend.
dotenv Load configuration and environment variables from a .env file.
@supabase/supabase-js Connect to Supabase database services from Node.js.
ws WebSocket support when real-time communication is needed.
nodemon Automatically restart the development server when files change.

Useful Development Commands

# Start a Node.js file
node server.js

# Start using nodemon
npx nodemon server.js

# Check installed packages
npm list --depth=0

Security reminder: keep database secrets in the backend .env file. Never commit secrets to GitHub or put Supabase service-role keys in frontend code.
