1. What is a Database?

Understand the basic idea before working with SQL or MongoDB.

Database

A database is a place where we store and organize data so that we can easily add, find, update and delete information.

Real-Life Example

A college may store student information such as name, email, mobile number, course and marks in a database.

Common Operations

  • Create data
  • Read data
  • Update data
  • Delete data

Why Use a Database?

  • Store large amounts of data
  • Search data quickly
  • Update information easily
  • Manage application data

2. SQL and Its Structure

SQL databases store data using tables.

What is SQL?

SQL stands for Structured Query Language. It is used to create, read, update and delete data in relational databases.

SQL Structure

SQL databases organize information into databases, tables, rows and columns. 

Database
   │
   ├── Students Table
   │      │
   │      ├── id
   │      ├── name
   │      ├── email
   │      ├── mobile
   │      └── course
   │
   └── Courses Table
          │
          ├── course_id
          └── course_name

Table = collection of related data | Row = one record | Column = one type of information

3. MongoDB and Its Structure

MongoDB is a NoSQL database that stores data as documents.

What is MongoDB?

MongoDB is a NoSQL database. Instead of storing data mainly in rows and columns, MongoDB stores data as JSON-like documents.

MongoDB Structure

MongoDB uses databases, collections and documents. Documents contain fields and values. 

Database
   │
   └── students Collection
          │
          ├── Document 1
          │    {
          │      name: "Rahul",
          │      email: "rahul@gmail.com",
          │      course: "JavaScript"
          │    }
          │
          └── Document 2
               {
                 name: "Priya",
                 email: "priya@gmail.com",
                 course: "React"
               }

Collection ≈ Table | Document ≈ Row/Record | Field ≈ Column

4. What is a Primary Key?

A primary key is a column used to uniquely identify each record in a SQL table. 

students

id    name       course
--------------------------------
1     Rahul      JavaScript
2     Priya      React
3     Aman       Python

Here, "id" is the Primary Key.
Each student has a unique id.

5. SQL vs MongoDB

Understand the basic difference between relational and NoSQL databases.

Feature SQL MongoDB
Type Relational Database NoSQL Database
Data Format Tables Documents
Structure Rows and Columns Documents and Fields
Collection Equivalent Table Collection
Record Equivalent Row Document
Query Language SQL MongoDB Query Language
Schema Usually structured/schema-based Flexible document structure
