Database Basics

Understand how databases store and organize data.

What is a Database?

A database is a structured place where we store, manage and retrieve data.

  • Stores application data
  • Organizes information
  • Allows searching and filtering
  • Supports CRUD operations

SQL Structure

SQL databases organize data using tables.

  • Database
  • Table
  • Rows
  • Columns
  • Primary Key

MongoDB Structure

MongoDB is a NoSQL database that stores data in document-based collections.

  • Database
  • Collection
  • Document
  • Fields

Primary Key

A primary key uniquely identifies each record in a SQL table.

  • Must be unique
  • Cannot be NULL
  • Identifies each row

Example

In a students table, the id column can be used as the primary key because every student has a unique ID.

SQL vs MongoDB

Understand the basic difference between SQL and MongoDB.

SQL MongoDB
Relational database NoSQL database
Uses tables Uses collections
Uses rows Uses documents
Uses columns Uses fields
Fixed schema Flexible schema
Uses SQL queries Uses MongoDB queries

How to Deploy Your Project on Netlify

Learn how to publish your HTML, CSS and JavaScript project online for free.

If your project is working correctly in VS Code using Live Server, you can deploy the same project on Netlify and get a live website link.

1

Open Netlify

Open the Netlify website in your browser.

Open Netlify
2

Login / Sign Up

Create a Netlify account or log in using your existing account.

3

Prepare Your Project

Make sure your project contains the required files. 

my-website/
│
├── index.html
├── style.css
└── script.js
4

Deploy Your Project

From the Netlify dashboard, choose the option for manually deploying your project and upload your website files/folder.

5

Wait for Deployment

Netlify will upload your files and publish your website. Wait until the deployment is completed.

6

Get Your Live Website
